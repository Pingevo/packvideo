## 1. อาการที่รายงาน

หลังยิง IMEI แล้วห่อเสร็จ ขั้นตอนถัดไปคือยิงเลขพัสดุเพื่อปิดคลิป
แต่หน้า sellcenter **ไม่เปลี่ยนอะไรเลย** — หัวข้อช่องยังเป็น `Imei` เหมือนเดิม
พนักงานไม่มีทางรู้ว่าจังหวะนี้ต้องยิงอะไร นอกจากจำเอาเอง

ยืนยันกับหน้างานแล้วว่า **ไม่มีแถบแดงขึ้น · ช่องไม่มีกรอบแดง · ป้ายไม่เปลี่ยน** — คือไม่มีอะไรเปลี่ยนสักอย่าง

## 2. สาเหตุราก (ยืนยันแล้ว)

`hook.js` **ปิดตัวเองทั้งหมด**บนหน้า sellcenter ไม่ใช่แค่ส่วนแสดงผล

```
hook.js:28-31   station = localStorage.getItem('packvideo.station_id')
                token   = localStorage.getItem('packvideo.token')
hook.js:498     var ACTIVE = !!(BASE && station && token);
hook.js:502-505 if (!ACTIVE) { debug(...); return; }   ← ออกก่อนผูกอะไรทั้งสิ้น
```

`localStorage` **แยกตาม origin** — `setup.html` เขียนค่าลง origin ของ `pack.digital.in.th`
แต่ `hook.js` ถูกโหลดและทำงานบน origin ของ sellcenter ซึ่งเป็นคนละที่เก็บกัน
`hook.js` จึงอ่านได้ `null` ทั้งคู่ → `ACTIVE = false` → `boot()` `return` ทันที

### ⚠️ ผลกระทบใหญ่กว่าเรื่องป้ายมาก

`boot()` ออกก่อนบรรทัดเหล่านี้ทั้งหมด

| บรรทัดที่ไม่ได้ทำงาน | สิ่งที่หายไป |
|---|---|
| `bindAjax()` | ไม่ดักการเรียก `/shopee/imei/get_order_new` → **ไม่เริ่มอัดคลิป** |
| `bindKey()` | ไม่ดัก Enter → **ไม่ปิดคลิปตอนยิงเลขพัสดุ** |
| `onLabelPage()` | ไม่จำเลขพัสดุจากหน้าใบปะหน้า |
| `startUi()` | ไม่มีแถบแดง ไม่เปลี่ยนป้าย ← อาการที่เห็น |

**บนเครื่องที่ไม่ได้ก๊อปค่าข้าม origin ด้วยมือ ระบบวิดีโอไม่ทำงานเลยแม้แต่นิดเดียว และเงียบสนิท**
ป้ายที่ยังเป็น `Imei` เป็นแค่อาการที่มองเห็นได้ง่ายที่สุดของปัญหานี้

## 4. ✅ สาเหตุที่ 2 — แก้แล้ว (`9aa0c6c`)

เดิมหาป้ายด้วยการเดาโครงสร้างเดียว

```
hook.js เดิม   var row = el.closest('tr'); var th = row && row.querySelector('th');
               if (th) { ... }        ← ไม่เจอก็เงียบ
```

คอมเมนต์บอกว่า "หน้าจริงเป็น `<th>` คู่กับ `<td>`" แต่หน้าจำลองที่ใช้ทดสอบวางช่องไว้ใน `<p>`
**บรรทัดนี้จึงไม่เคยถูกทดสอบเลย**

ตอนนี้ `findLabel()` ลองหลายทางเรียงจากมั่นใจที่สุดลงไป — `label[for]` · `<th>` ในแถว ·
`<td>` แรกที่ไม่ใช่ช่อง · `<label>` ที่ครอบอยู่ · ตัวก่อนหน้าช่อง — แล้ว**กรองด้วยข้อความ
ว่าต้องเขียนว่า IMEI จริง**

ตัวกรองข้อความไม่ใช่ของแถม แต่จำเป็น — บนหน้าจำลอง ตัวที่อยู่ก่อนช่องสแกนคือ
`ผู้ใช้: tester` ซึ่งผ่านเกณฑ์โครงสร้างทุกข้อ ถ้าเชื่อตำแหน่งอย่างเดียวจะไปเปลี่ยนชื่อ
คนใช้งานเป็น "เลขพัสดุ" แทน · **เรากำลังแก้หน้าของระบบอื่น ห้ามทำของเขาพัง**

หาไม่เจอก็ไม่แตะอะไรเลย แล้วยิงสัญญาณ `ui_degraded` บอก — แถบแดงกับ placeholder
ยังทำงานอยู่ ป้ายเป็นของแถม ไม่ใช่ตัวหลัก

เก็บ `innerHTML` แทน `textContent` ด้วย ป้ายจริงอาจเป็น `<b>Imei</b> <span>*</span>` —
โค้ดเดิมคืนค่าด้วย `textContent` จะทำโครงสร้างลูกหายถาวร

### 5.2 ✅ แข่งเวลากับ bridge — แก้แล้ว (`7250bdd`)

เจอตอนตรวจกับหน้า sellcenter จริงที่ `localhost:2222` · `hook.js` เดิมอ่าน
`station_id`/`token` **ครั้งเดียวตอนสคริปต์ถูกประเมิน** แล้วคำนวณ `ACTIVE` ค้างไว้
แต่ `bridge.html` ส่งค่ามาแบบ async (รอ iframe โหลด → `postMessage`)

**แปลว่า bridge ที่เพิ่ง merge เข้ามาใช้ได้จริงตั้งแต่การโหลดหน้าครั้งที่สองเป็นต้นไปเท่านั้น**
ครั้งแรกหลังล้าง localStorage จะอ่านได้ `null` ไปก่อนเสมอ

ตอนนี้ `refreshConfig()` อ่านใหม่ได้ทุกครั้ง และ `waitForConfig()` รอสูงสุด 10 วินาที
โดยฟังสามทางที่พลาดคนละแบบ — `postMessage` จาก bridge (เร็วสุด และ hook เขียนค่าลง
localStorage ให้เอง) · `storage` event · poll ทุก 250 ms · ตรวจ `ev.origin` ทุกครั้ง

ผลพลอยได้: **ฝั่ง sellcenter เหลือแค่ฝัง iframe ไม่ต้องเขียน listener เอง**

ข้อห้ามเดิมยังอยู่ครบ — เครื่องที่ไม่ได้ตั้งค่าไม่ถูกแตะเลย ระหว่างรอแค่ฟังเงียบๆ
การผูกตัวดักย้ายไปอยู่ใน `start()` ที่เรียกเฉพาะตอนมีค่าครบ

## 7. ขั้นตอนถัดไป — เหลือฝั่ง sellcenter อย่างเดียว

ฝั่ง packvideo แก้ครบแล้วและทดสอบแล้วทั้งหมด · ที่เหลือเป็นการแก้ในซอร์สของ sellcenter

1. **ฝัง bridge ก่อนโหลด hook.js** — ตอนนี้หน้า `/shopee/imei` ยังไม่มี ค้นคำว่า `bridge.html` ในหน้าไม่เจอ

   ```html
   <iframe hidden src="https://pack.digital.in.th/bridge.html"></iframe>
   ```

   แค่นี้พอ ไม่ต้องเขียน listener แล้ว `hook.js` รับ message เองและเขียน localStorage ให้

2. **เพิ่ม origin ของ sellcenter เข้า `ALLOWED_ORIGINS`** ถ้ายังไม่มี — ตอนนี้มีแค่ `https://digital.in.th` · ถ้าจะทดสอบที่ `http://localhost:2222` ต้องเพิ่มเข้าไปด้วย ไม่งั้น bridge ปฏิเสธและ `frame-ancestors` บล็อก iframe

3. **ตอนทดสอบในเครื่อง** ต้องเปลี่ยน `src` ของ hook.js จาก `https://pack.digital.in.th/hook.js` เป็น `http://localhost:1338/hook.js` ไม่งั้นสัญญาณและคลิปวิ่งไปเข้าเซิร์ฟเวอร์จริง

4. เปิดหน้างานแล้วยิงเลขพัสดุจริงดูว่าปิดคลิปได้ · ถ้ามีอะไรผิด เปิด `monitor.html` ดูคำเตือน — ตอนนี้มีทั้ง `hookdead:` (โต๊ะต่ออยู่แต่ hook ไม่ทำงาน) และ `ui:` (แตะหน้าเดิมได้ไม่ครบ)
