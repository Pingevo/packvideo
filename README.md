# packvideo

ระบบบันทึกวิดีโอตอนแพ็คสินค้า — 1 คลิปต่อ 1 ออเดอร์ ผูกกับเลขออเดอร์และเลขพัสดุอัตโนมัติ
เพื่อใช้เป็นหลักฐานสู้เคสกับแพลตฟอร์ม (Shopee/Lazada/TikTok) เคลมกับบริษัทขนส่ง และตรวจสอบภายใน

> **สถานะ: ยังไม่เริ่มเขียนโค้ดระบบจริง** — ตอนนี้มีเอกสารและ spike ทดสอบสมมติฐาน

ทำงานคู่กับระบบเดิม `sellcenter` (หน้าแพ็คสินค้า `/shopee/imei`) โดยเป็นคนละโปรเจกต์
คนละ container — ระบบเดิมเรียกผ่าน `hook.js` 1 บรรทัด

### รัน S1

เปิด `spikes/s1-mediarecorder/index.html` ใน**เบราว์เซอร์ของเครื่องโต๊ะแพ็ค**
แล้วปล่อยให้แท็บแสดงอยู่บนหน้าจอ — การทดสอบเริ่มเองและสรุปผลให้ในหน้าเดียว

แท็บที่ถูกซ่อนอยู่จะถูกเบราว์เซอร์ throttle จนได้คลิปเกือบเปล่า หน้าทดสอบจึงรอจนแท็บ
ถูกแสดงก่อนค่อยเริ่มอัด และจะรายงานว่า `สรุปไม่ได้` แทนที่จะรายงานว่าผ่านถ้าเงื่อนไขไม่ครบ

## เริ่มพัฒนา

ต้องใช้ **Node 22** — เครื่องพัฒนามี node 12 ของ sellcenter อยู่ ระวังหยิบผิดตัว

```bash
nvm use          # อ่านจาก .nvmrc
npm install
cp .env.example .env
npm run dev      # http://127.0.0.1:1338
```

ตรวจว่าทำงานถูก — ใช้ได้ทั้งเครื่องพัฒนาและเครื่องโต๊ะแพ็ค:

```bash
npm run smoke
```

```bash
BASE=https://packvideo.digital.in.th npm run smoke
```

## หลักการที่ห้ามละเมิด

1. **ระบบวิดีโอพังได้ งานแพ็คห้ามหยุด** — ทุกการเชื่อมต่อกับระบบเดิมเป็นแบบยิงแล้วไม่รอคำตอบ
2. **ไม่บันทึกเสียง** — ไม่มีสวิตช์ให้เปิด (PDPA)
3. **station token อ่านคลิปไม่ได้** — token อยู่ในหน้าเว็บที่ใครก็ view-source ได้
4. **ลบไฟล์ได้ ลบ metadata ไม่ได้** — ต้องตอบได้เสมอว่าคลิปเคยมีและถูกลบเมื่อไร
5. **retention job ยอมไม่ลบ ดีกว่าลบผิด** — คลิปที่ pin คือหลักฐานของเคสที่กำลังสู้เงินอยู่
