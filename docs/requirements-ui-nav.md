> ต่อยอดจาก `requirements.md` §FR-6 (pin) · §FR-9 (ตั้งค่า) · §NFR-1 (ผลกระทบต่องานแพ็ค) · §NFR-4 (PDPA)

## 1. ปัญหาที่กำลังแก้

| # | ปัญหาที่พบในโค้ดปัจจุบัน | ผลกระทบ |
|---|---|---|
| P-1 | `/setup.html` **เข้าไม่ถึงเลยหลังตั้งค่าเสร็จ** — `rec.html` โชว์ลิงก์ไปหน้าตั้งค่าเฉพาะตอนยังไม่ได้ตั้งค่า พอตั้งเสร็จลิงก์หายไป | A1/A4 ต้องพิมพ์ URL เองเพื่อเปลี่ยนกล้องหรือย้ายโต๊ะ — คนหน้างานทำไม่เป็น |
| P-2 | ทางเข้าคู่มือเป็นลิงก์ตัวอักษร 12px opacity .6 มุมขวา | มองไม่เห็น เท่ากับไม่มี |

## 2. ขอบเขต (ตัดสินแล้ว)

| หัวข้อ | ค่าที่เลือก |
|---|---|
| สิ่งที่อยู่ใต้ icon | **ตั้งค่าเครื่อง + คู่มือ + ดูคลิปย้อนหลัง** |
| หน้าที่ต้องมี icon | ทั้ง 4 หน้า: `rec.html` · `setup.html` · `monitor.html` · `clips.html` |
| พฤติกรรมเมื่อกด | **แผงลอยทับหน้าเดิม** — ไม่เปลี่ยน URL ไม่ออกจากหน้า |
| ระหว่างกำลังอัด | **ล็อกเฉพาะรายการที่อันตราย** ที่เหลือใช้ได้ตามปกติ |
| คนแพ็คดูคลิปได้แค่ไหน | รายการ = โต๊ะตัวเอง · ค้นด้วยเลขออเดอร์ = ได้ทุกโต๊ะ · ย้อนหลังเท่า retention เต็ม |
| คนแพ็คทำอะไรได้ | ดู · ดาวน์โหลดไฟล์คลิป · ตรึงกันโดนลบ |

## 7. เรื่องราวผู้ใช้และเกณฑ์ตรวจรับ

### US-N1 · A1 — กล้องเบลอ อยากเปลี่ยนกล้อง
**เมื่อ** คลิปปัจจุบันปิดแล้ว และกด icon
**เกณฑ์ผ่าน** — URL ไม่เปลี่ยน · หน้าไม่รีโหลด · พรีวิวเปลี่ยนเป็นกล้องใหม่ · คิวที่ค้างอยู่ไม่หาย

### US-N2 · A1 — กด icon ระหว่างที่กำลังอัดอยู่
**เกณฑ์ผ่าน** — การอัดไม่สะดุด · ไฟล์คลิปที่ได้ครบไม่ขาด · ปุ่มเปลี่ยนโต๊ะ/กล้อง/ล้างค่ากดไม่ได้พร้อมเหตุผล · เมื่อคลิปปิด ปุ่มกลับมากดได้

### US-N3 · A4 — ย้ายเครื่องไปโต๊ะอื่น
**เกณฑ์ผ่าน** — ยังได้การกันโต๊ะชนตาม FR-9.2 · ไม่ต้องพิมพ์ URL เอง

### US-N4 · A1 — โดนทักว่าแพ็คขาด
**เมื่อ** CS แจ้งเลขออเดอร์มา คนแพ็คกด icon → ดูคลิปย้อนหลัง → วางเลขออเดอร์
**เกณฑ์ผ่าน** — เจอคลิปแม้เป็นออเดอร์ของโต๊ะอื่น · เล่นดูได้ · ดาวน์โหลดได้ · ตรึงได้ · **ไม่เห็นปุ่มสร้างลิงก์และปุ่มถอนตรึง**

### US-N5 · A2 หัวหน้าคลัง — ตรวจงานที่โต๊ะ
**เมื่อ** เดินมาที่โต๊ะ กด icon ดูคลิปย้อนหลังของโต๊ะนั้น
**เกณฑ์ผ่าน** — เห็นคลิปของโต๊ะนั้นเรียงใหม่ก่อน · ย้อนได้เท่า retention · ไม่ต้องออกจาก `rec.html`

### US-N6 · A1 — เปิดดูคลิปเก่าระหว่างที่คิวยังค้าง
**เกณฑ์ผ่าน** — ต้องไม่ทำให้คิวอัพโหลดช้าลงจนคลิปตกค้างเพิ่ม (NFR-10.6)
