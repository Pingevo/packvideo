# ข้อบกพร่อง — หน้า sellcenter ไม่บอกว่าต้องยิงเลขพัสดุ (และ hook.js ไม่ทำงานเลย)

> บันทึกเมื่อ 2026-08-18 · สถานะ: **สาเหตุที่ 1 แก้แล้ว · สาเหตุที่ 2 ยังค้าง**

---

## 1. อาการที่รายงาน

หลังยิง IMEI แล้วห่อเสร็จ ขั้นตอนถัดไปคือยิงเลขพัสดุเพื่อปิดคลิป
แต่หน้า sellcenter **ไม่เปลี่ยนอะไรเลย** — หัวข้อช่องยังเป็น `Imei` เหมือนเดิม
พนักงานไม่มีทางรู้ว่าจังหวะนี้ต้องยิงอะไร นอกจากจำเอาเอง

ยืนยันกับหน้างานแล้วว่า **ไม่มีแถบแดงขึ้น · ช่องไม่มีกรอบแดง · ป้ายไม่เปลี่ยน** — คือไม่มีอะไรเปลี่ยนสักอย่าง

---

## 2. สาเหตุราก (ยืนยันแล้ว)

`hook.js` **ปิดตัวเองทั้งหมด**บนหน้า sellcenter ไม่ใช่แค่ส่วนแสดงผล

```
hook.js:28-31   station = localStorage.getItem('packvideo.station_id')
                token   = localStorage.getItem('packvideo.token')
hook.js:498     var ACTIVE = !!(BASE && station && token);
hook.js:502-505 if (!ACTIVE) { debug(...); return; }   ← ออกก่อนผูกอะไรทั้งสิ้น
```

`localStorage` **แยกตาม origin** — `setup.html` เขียนค่าลง origin ของ `pack.digital.in.th`
แต่ `hook.js` ถูกโหลดและทำงานบน origin ของ sellcenter ซึ่งเป็นคนละที่เก็บกัน
`hook.js` จึงอ่านได้ `null` ทั้งคู่ → `ACTIVE = false` → `boot()` `return` ทันที

### ⚠️ ผลกระทบใหญ่กว่าเรื่องป้ายมาก

`boot()` ออกก่อนบรรทัดเหล่านี้ทั้งหมด

| บรรทัดที่ไม่ได้ทำงาน | สิ่งที่หายไป |
|---|---|
| `bindAjax()` | ไม่ดักการเรียก `/shopee/imei/get_order_new` → **ไม่เริ่มอัดคลิป** |
| `bindKey()` | ไม่ดัก Enter → **ไม่ปิดคลิปตอนยิงเลขพัสดุ** |
| `onLabelPage()` | ไม่จำเลขพัสดุจากหน้าใบปะหน้า |
| `startUi()` | ไม่มีแถบแดง ไม่เปลี่ยนป้าย ← อาการที่เห็น |

**บนเครื่องที่ไม่ได้ก๊อปค่าข้าม origin ด้วยมือ ระบบวิดีโอไม่ทำงานเลยแม้แต่นิดเดียว และเงียบสนิท**
ป้ายที่ยังเป็น `Imei` เป็นแค่อาการที่มองเห็นได้ง่ายที่สุดของปัญหานี้

## 3. ✅ ทางแก้ — merge แล้วพร้อมแก้เพิ่มสองจุด

`origin/feat/sellcenter-bridge` merge เข้าสาขาปัจจุบันแล้ว (`6996df9`)

| commit | ทำอะไร |
|---|---|
| `1e51e7b` | `bridge.html` — อ่าน `localStorage` ของ origin นี้ แล้ว `postMessage` กลับไปให้ parent ที่ฝัง iframe |
| `8ebd648` | เปิด CORS ให้ `GET /api/stations` · `claim`/`heartbeat`/`release` ยังเป็น same-origin |

### ผลการตรวจโค้ดก่อน merge

**ส่วนที่ทำถูกและคงไว้ทั้งหมด** — `postMessage` ระบุ target origin ตรงๆ ไม่ใช้ `'*'`
(นี่คือด่านจริง เบราว์เซอร์บังคับเอง) · เทียบ `document.referrer` กับ allowlist ก่อนเสมอ ·
อ่าน referrer ไม่ได้ = ไม่ส่ง · `signalCors` เทียบกับ `config.allowedOrigins` ไม่สะท้อน origin มั่ว
ไม่เปิด credentials

**สองจุดที่แก้เพิ่มใน `676d56d`**

| จุด | ปัญหา | ที่แก้ |
|---|---|---|
| 1 | `bridge.html` hardcode ไว้ **16 origin** พร้อมคอมเมนต์ว่าต้องตรงกับ `ALLOWED_ORIGINS` — แต่ `.env` มี **1 origin** คือ `digital.in.th` **ไม่ตรงอยู่แล้วตั้งแต่แรก** แปลว่ายื่น token ให้อีก 15 origin ที่เซิร์ฟเวอร์เองไม่ยอมรับ | ย้ายไปเสิร์ฟผ่าน `src/routes/bridge.js` ฉีด `config.allowedOrigins` ตอนรัน · เหลือแหล่งความจริงเดียวคือ `.env` |
| 2 | **ไม่มี `frame-ancestors` เลยทั้งระบบ** ไม่มี helmet ไม่มี CSP ไม่มี `X-Frame-Options` — ทุกหน้าโดนฝัง iframe ได้ รวม `clips.html` ที่มีปุ่มสร้างลิงก์ส่งคนนอกและปุ่มถอนตรึง (ปัญหาเดิม ไม่ใช่สาขานี้ทำ) | ตั้ง `'none'` เป็นค่าเริ่มต้นทั้งระบบ · `/bridge.html` เป็นข้อยกเว้นเดียว |

### ⚠️ ยังพิสูจน์ไม่ได้ว่าหน้างานหายจริง

ตรวจแล้วเฉพาะฝั่งเซิร์ฟเวอร์ (header ถูก · allowlist ตรง · smoke 9/9 ผ่าน)
**ยังไม่ได้ทดสอบกับหน้า sellcenter จริง** — ต้องไปดูที่หน้างานว่าแถบแดงขึ้นแล้วหรือยัง

## 4. สาเหตุที่ 2 — ยังพิสูจน์ไม่ได้จนกว่าจะแก้ข้อ 2 เสร็จ

ถึง `ACTIVE` จะเป็น true แล้ว ป้ายก็อาจยังไม่เปลี่ยนอยู่ดี

```
hook.js:328-330   var row = el.closest && el.closest('tr');
                  var th  = row && row.querySelector('th');
                  if (th) { ... th.textContent = 'เลขพัสดุ'; }
```

โค้ดสมมติว่าหน้าจริงวางช่องไว้ในตาราง โดยป้ายเป็น `<th>` คู่กับ `<td>` ที่มี `input`
แต่หน้าจำลองที่ใช้ทดสอบ (`src/dev/fake-imei-page.html:38`) วาง `#txt_imei` ไว้ใน `<p>` เฉยๆ
**บรรทัดเปลี่ยนป้ายนี้จึงไม่เคยถูกทดสอบเลย** และถ้าหาไม่เจอมันเงียบ ไม่ error

ส่วน `placeholder` และกรอบแดงเกาะกับ `#txt_imei` ตรงๆ อันนั้นน่าจะติด

|---|---|---|

| FR-13.2 | ตอนที่ระบบรอเลขพัสดุ หน้าที่พนักงานมองอยู่ต้องบอกเองว่า**ต้องยิงเลขพัสดุ** ไม่ใช่ IMEI | **must** |
| FR-13.3 | ต้องบอกด้วยว่า**เลขไหน**ที่รออยู่ และ**เหลือเวลาเท่าไร**ก่อนเลิกรอ | **must** |

| FR-13.5 | ⛔ **เครื่องที่ตั้งค่าแล้วแต่ hook ทำงานไม่ได้ ต้องไม่เงียบ** — ตอนนี้แยกไม่ออกระหว่าง "เครื่องนี้ไม่ได้ใช้ระบบวิดีโอ" กับ "ตั้งค่าแล้วแต่พัง" ทั้งสองกรณีเงียบเหมือนกันหมด | **must** |
| FR-13.6 | การเปลี่ยนหน้าของ sellcenter ต้องคืนค่าเดิมได้ครบเมื่อเลิกรอ | **must** |

> **FR-13.5 คือบทเรียนจริงของเรื่องนี้** — ถ้ามีสัญญาณเตือนตั้งแต่แรกว่า "ตั้งค่าแล้วแต่ hook
