# packvideo

ระบบบันทึกวิดีโอตอนแพ็คสินค้า — **1 คลิปต่อ 1 ออเดอร์** ผูกกับเลขออเดอร์และเลขพัสดุอัตโนมัติ
เพื่อใช้เป็นหลักฐานสู้เคสกับแพลตฟอร์ม เคลมกับขนส่ง และตรวจสอบภายใน

---

## ⚠️ สถานะ: ยังไม่พร้อมใช้งานจริง

โค้ดเขียนและทดสอบในเครื่องแล้ว แต่ **ยังไม่เคยติดตั้งที่ไหน ไม่เคยเจอกล้องจริง และยังไม่ได้ต่อกับหน้าแพ็ค**

| ส่วน | สถานะ |
|---|---|
| เฟส 1 — สัญญาณ · ทะเบียนโต๊ะ · ค้นหา · เฝ้าดูระบบ | ✅ เขียนและทดสอบแล้ว |
| เฟส 2a — หน้าต่างอัด · อัปโหลดเป็นชิ้น · สตรีม | ✅ เขียนและทดสอบแล้ว |
| เฟส 2c — ส่งออก · ตรึงคลิป · ลบตามกำหนด · ลิงก์ภายนอก | ✅ เขียนและทดสอบแล้ว |
| สำรอง `_pinned/` | ⬜ ยังไม่ทำ (มีวิธีทำด้วยมือใน [usage.md](docs/usage.md)) |
| ตรึงคลิปจากสถานะขนส่ง | ⬜ เลื่อนไปหลัง pilot |

**ยังพิสูจน์ไม่ได้จนกว่าจะติดตั้งจริง**

| เรื่อง | ติดอะไร |
|---|---|
| กล้องจริง · คลิปยาว ~105 วิ · CPU ตลอดกะ 8 ชม. | ต้องมีกล้องและเครื่องโต๊ะแพ็ค |
| **ค่า bitrate ที่ยังอ่านเลขพัสดุออก** | ต้องทดสอบกับกล้องจริง — **ความเสี่ยงที่ยังไม่ปิด** ถ้าอ่านไม่ออกต้องทบทวนการเก็บ 30 วันทั้งก้อน |
| ท่อส่งออกหลักฐาน | ffmpeg บนเครื่องพัฒนาไม่มี `drawtext` (บน Docker มี) |
| ต่อกับหน้าแพ็คจริง | ต้องมี subdomain + SSL cert |

## ระบบทำงานยังไง

```
สแกน IMEI ──Enter──▶ เริ่มอัด
                        │
              API ตอบ ──┼─── เจอออเดอร์ ──▶ ผูก ordersn เก็บคลิป
                        └─── ไม่เจอ/ราคาผิด ──▶ ทิ้งคลิป
                        │
        หน้าใบปะหน้า ───▶ จำเลขพัสดุไว้
                        │
        [ หยิบของ · ใส่กล่อง · ปิดกล่อง · แปะใบปะหน้า ]
                        │
    สแกนบาร์โค้ดกล่อง ──┼─── ตรงกับที่จำไว้ ──▶ ปิดคลิป ✅
                        └─── ไม่ตรง ──▶ ⚠️ เตือนแปะผิดใบ
```

**หลักการที่ห้ามละเมิด**

- ระบบวิดีโอพังได้ **งานแพ็คห้ามหยุด** — `/signal` ตอบ 204 เสมอ ไม่ว่าเกิดอะไร
- **ไม่บันทึกเสียง** ทุกกรณี และไม่มีสวิตช์ให้เปิด
- **ห้ามใส่รหัสผ่านหรือ token ลงในซอร์ส** — ค่าตั้งทั้งหมดมาจาก environment
- งานลบข้อมูล **ยอมไม่ลบดีกว่าลบผิด**
- ไฟล์ต้นฉบับแก้ไม่ได้หลังปิดคลิป — มี checksum กำกับ

## เริ่มพัฒนา

ขั้นตอนเต็มที่ [docs/dev-setup.md](docs/dev-setup.md) — ย่อๆ คือ

```bash
nvm use && npm install && cp .env.example .env
```

```bash
npm run setup-mongo
```

```bash
npm run dev
```

> ต้องใช้ **Node 22** — เครื่องพัฒนามี Node 12 ของ sellcenter อยู่ด้วย
> ทุก `npm run` ตรวจรุ่นให้ก่อนแล้วบอกถ้าหยิบผิดตัว

## ทดสอบ

```bash
npm run smoke
```

| คำสั่ง | ทดสอบอะไร | จำนวน |
|---|---|---|
| `npm run smoke` | บริการขึ้นและต่อทุกอย่างได้ | 9 |
| `npm run e2e` | วงจรชีวิตคลิปครบวง + สตรีมพร้อม Range | 17 |
| `npm run e2e:retention` | ลบตามกำหนด รวมกรณีย้ายไม่สำเร็จ | 13 |
| `npm run e2e:share` | ลิงก์ภายนอก หมดอายุ ยกเลิก บันทึกการเปิดดู | 15 |
| `/dev/queue-test.html` | คิวชิ้นวิดีโอตอนเน็ตขาดและปิดหน้า | 10 |

รวม **64 ข้อ** — ไม่ต้องมีกล้องหรือเบราว์เซอร์ ยกเว้นชุดสุดท้าย
